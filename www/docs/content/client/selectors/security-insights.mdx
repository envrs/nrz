Security insight selectors rely on data provided by
[Socket](https://socket.dev/). Using any of these selectors triggers a
network call to fetch package report data.

<Aside type="note">
  Security selectors require fetching data from Socket's API. This
  adds latency to queries — the data is fetched before the query runs.
  Keep this in mind for interactive use.
</Aside>

## Malware & threats

### `:malware`

Matches packages that contain malware. This is a binary selector — a
package either has malware or it doesn't:

<Code code="$ nrz query ':malware'" title="Terminal" lang="bash" />

<Aside type="tip">
  `:malware` matches only high-confidence malware alerts (`malware`
  and `gptMalware`). For broader vulnerability detection with
  configurable severity levels, use [`:vuln`](#vulnerable--vuln).
</Aside>

### `:squat` / `:squat(<type>)`

Matches packages with names similar to popular packages
(typosquatting).

<Code code="$ nrz query ':squat'" title="Terminal" lang="bash" />

`:squat` without arguments matches any severity. Filter with:

| Type              | Description               |
| ----------------- | ------------------------- |
| `critical` or `0` | High-confidence typosquat |
| `medium` or `2`   | Possible typosquat        |
| `none`            | Not a typosquat           |

### `:suspicious`

Matches packages with artificially inflated GitHub stars (bots,
crowdsourcing, etc.):

<Code code="$ nrz query ':suspicious'" title="Terminal" lang="bash" />

### `:confused`

Matches packages affected by manifest confusion — the published
`package.json` differs from what's in the tarball:

<Code code="$ nrz query ':confused'" title="Terminal" lang="bash" />

## Vulnerabilities

### `:vulnerable` / `:vuln`

Matches packages with vulnerability or security anomaly alerts with
severity >= medium (excludes low-severity alerts by default):

<Code code="$ nrz query ':vulnerable'" title="Terminal" lang="bash" />

The `:vuln` alias works identically:

<Code code="$ nrz query ':vuln'" title="Terminal" lang="bash" />

#### `:vuln(<level>)`

Filter by severity level:

| Level             | Alert types matched                     |
| ----------------- | --------------------------------------- |
| `critical` or `0` | `criticalCVE`                           |
| `high` or `1`     | `cve`                                   |
| `medium` or `2`   | `potentialVulnerability`, `gptSecurity` |
| `low` or `3`      | `mildCVE`, `gptAnomaly`                 |

Comparators are supported:

<Code
  code={`$ nrz query ':vuln(critical)'
$ nrz query ':vuln(">1")'
$ nrz query ':vuln(">=medium")'`}
  title="Terminal"
  lang="bash"
/>

### `:cve(<id>)`

Matches packages with a specific CVE alert:

<Code
  code="$ nrz query ':cve(CVE-2023-1234)'"
  title="Terminal"
  lang="bash"
/>

Match packages with any CVE:

<Code code="$ nrz query ':cve'" title="Terminal" lang="bash" />

### `:cwe(<id>)`

Matches packages with a specific CWE alert:

<Code
  code="$ nrz query ':cwe(CWE-79)'"
  title="Terminal"
  lang="bash"
/>

### `:severity(<level>)`

Matches packages by CVE severity level:

| Level             | Description            |
| ----------------- | ---------------------- |
| `critical` or `0` | Critical severity CVEs |
| `high` or `1`     | High severity CVEs     |
| `medium` or `2`   | Medium severity CVEs   |
| `low` or `3`      | Low severity CVEs      |

Comparators are supported:

<Code
  code={`$ nrz query ':severity(critical)'
$ nrz query ':severity(">1")'
$ nrz query ':severity(">=medium")'`}
  title="Terminal"
  lang="bash"
/>

## Licensing

### `:license(<type>)`

Matches packages based on license issues:

| Type         | Description                              |
| ------------ | ---------------------------------------- |
| `unlicensed` | No license                               |
| `misc`       | Fine-grained license problems            |
| `restricted` | Non-permissive license                   |
| `ambiguous`  | Ambiguous licensing                      |
| `copyleft`   | Copyleft license (GPL, etc.)             |
| `unknown`    | License data found but type undetermined |
| `none`       | No license data at all                   |
| `exception`  | SPDX license exception                   |

<Code
  code={`# Find packages with copyleft licenses
$ nrz query ':license(copyleft)'

# Find unlicensed packages

$ nrz query ':license(unlicensed)'

# Find packages with any license

$ nrz query ':license'`} title="Terminal" lang="bash" />

### `:score(<rate>, <kind>)`

Match packages by security score:

| Parameter | Description                                          |
| --------- | ---------------------------------------------------- |
| `rate`    | Score value 0–100 (or 0–1), with optional comparator |
| `kind`    | Score category (optional, default: `overall`)        |

Available kinds: `overall`, `license`, `maintenance`, `quality`,
`supplyChain`, `vulnerability`.

<Code
  code={`# Packages with exactly 0.8 overall score
$ nrz query ':score(80)'

# Packages with score > 0.8

$ nrz query ':score(">0.8")'

# Low maintenance score

$ nrz query ':score("<=0.5", "maintenance")'`} title="Terminal"
lang="bash" />

## Common audit queries

Run a comprehensive security audit:

<Code
  code={`# Critical issues
$ nrz query ':malware, :cve, :obfuscated'

# Vulnerability scan with severity

$ nrz query ':vuln(critical), :vuln(high)'

# Supply chain risks

$ nrz query ':abandoned, :unmaintained, :unknown'

# License compliance

$ nrz query ':license(copyleft), :license(unlicensed)'

# Code behavior audit

$ nrz query ':eval, :shell, :network, :fs'`} title="Terminal"
lang="bash" />
