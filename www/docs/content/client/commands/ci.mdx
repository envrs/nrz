Usage:

<Code code="$ nrz ci" title="Terminal" lang="bash" />

Clean install for CI pipelines. Removes `node_modules` and installs
dependencies exactly as specified in `nrz-lock.json`, failing if the
lockfile is missing or out of date.

## Lifecycle scripts

Like [`nrz install`](/client/commands/install), `nrz ci` runs **no
lifecycle scripts** of dependencies by default. To opt in:

<Code
  code={`# Allow scripts for specific packages
$ nrz ci --allow-scripts="#esbuild"

# Persist the query for ci in nrz.json

$ nrz config set "command.ci.allow-scripts=#esbuild"

# Or build after install (skips packages with malware alerts)

$ nrz ci && nrz build`} title="Terminal" lang="bash" />

See [`nrz build`](/client/commands/build) for build targets.

## Workspaces

`nrz ci` reads workspaces from `nrz.json` only. If they are declared
only in `package.json` or `pnpm-workspace.yaml`, it warns and ignores
them: run `nrz install` and commit `nrz.json` (see
[Workspaces](/client/workspaces#saving-workspaces-to-nrzjson)).

## Options

| Flag                      | Description                                                                                           |
| ------------------------- | ----------------------------------------------------------------------------------------------------- |
| `--allow-scripts=<query>` | Allow matching packages to run lifecycle scripts                                                      |
| `--allow-skills=<query>`  | Link the agent skills of matching packages (never saved), see [`nrz skills`](/client/commands/skills) |
| `--skills-dir=<path>`     | Dirs to link agent skills into, see [`nrz skills`](/client/commands/skills)                           |
