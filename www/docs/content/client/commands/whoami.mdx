Usage:

<Code code="$ nrz whoami" title="Terminal" lang="bash" />

Look up the username for the currently active token, when logged into
a registry.

To target a specific configured registry by alias, use
[`nrz registry <alias> whoami`](/client/commands/registry). See
[Targeting a specific registry](/client/registries#targeting-a-specific-registry).
