Usage:

<Code code="$ nrz publish" title="Terminal" lang="bash" />

Create a tarball from a package and publish it to the configured
registry. This command will pack the package in the current directory
or specified folder, and then upload it to the configured registry.

The registry is the package's `publishConfig.registry` if set, else
`--registry`, else a configured alias. `publishConfig.registry` alone
is enough.

## Options

### tag

Publish the package with the given tag

<Code code="$ nrz publish --tag=<tag>" title="Terminal" lang="bash" />

### access

Set access level (public or restricted)

<Code
  code="$ nrz publish --access=<level>"
  title="Terminal"
  lang="bash"
/>

### otp

Provide an OTP to use when publishing a package.

<Code code="$ nrz publish --otp=<otp>" title="Terminal" lang="bash" />

### publish-directory

Directory to use for pack and publish operations instead of the
current directory. The directory must exist and nothing will be copied
to it.

<Code
  code="$ nrz publish --publish-directory=<path>"
  title="Terminal"
  lang="bash"
/>

## Publishing in CI

### Service token

For the nrz.io registry, publish from CI with a **service token**. A
personal token answers every publish with a one-time-password
challenge and fails unattended with `EOTP`. Set it as `NRZ_TOKEN`:

<Code
  code={`      - run: nrz publish
        env:
          NRZ_TOKEN: \${{ secrets.NRZ_TOKEN }}`}
  title="github-actions.yml"
  lang="yaml"
/>

See [CI & automation](/registry/publishing/ci) for the full workflow,
and
[Authentication — CI](/client/auth#ci-and-other-headless-environments)
for how token environment variables are named.

### OIDC

If your CI provider supports OpenID Connect, nrz can publish without
any stored tokens. On GitHub Actions, add `id-token: write` to your
job's permissions and nrz handles authentication automatically.

<Aside type="note">
  This requires a registry that supports OIDC trusted publishing. The
  nrz.io registry currently does not — use a service token there.
</Aside>

See [Authentication — OIDC](/client/auth#oidc-openid-connect) for full
details on supported providers and configuration.

<Code
  code={`jobs:
  publish:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      id-token: write
    steps:
      - uses: actions/checkout@v4
      - uses: khulnasoft/setup-nrz@main
      - run: nrz publish`}
  title="github-actions.yml"
  lang="yaml"
/>
