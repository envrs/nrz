## Usage

<Code
  code="$ nrz create <initializer> [args...]"
  title="Terminal"
  lang="bash"
/>

Initialize a new project from a template package.

## Description

The `nrz create` command works like `npm create` and `bun create`,
automatically prepending "create-" to the package name and executing
it.

For example, running:

<Code
  code="$ nrz create react-app my-app"
  title="Terminal"
  lang="bash"
/>

Will fetch and execute the `create-react-app` package with the
arguments `my-app`.

If a satisfying instance of the create package exists in the local
`node_modules` folder, then that will be used. Otherwise, nrz will
install the package to its XDG data directory without modifying your
local dependencies.

## Examples

### Start a Next.js Project

<Code
  code="$ nrz create next-app my-app"
  title="Terminal"
  lang="bash"
/>

This fetches and runs `create-next-app my-app`. You can also pass
options through:

<Code
  code={`$ nrz create next-app my-app --typescript --tailwind --eslint
$ nrz create next-app my-app --use-pnpm  # or any create-next-app flag`}
  title="Terminal"
  lang="bash"
/>

### Create a React App

<Code
  code="$ nrz create react-app my-app"
  title="Terminal"
  lang="bash"
/>

This executes `create-react-app my-app`

### Create a Vite Project

<Code
  code="$ nrz create vite my-project"
  title="Terminal"
  lang="bash"
/>

This executes `create-vite my-project`

### Create a SvelteKit Project

<Code
  code="$ nrz create svelte@latest my-app"
  title="Terminal"
  lang="bash"
/>

This executes `create-svelte@latest my-app`

### Use a Scoped Template

<Code
  code="$ nrz create @scope/template my-app"
  title="Terminal"
  lang="bash"
/>

This executes `@scope/create-template my-app`

### Skip Confirmation Prompts

Use `--yes` to automatically accept the install prompt:

<Code
  code="$ nrz create next-app my-app --yes"
  title="Terminal"
  lang="bash"
/>

## Options

### `--allow-scripts <query>`

Filter which packages are allowed to run lifecycle scripts using DSS
query syntax.

<Code
  code="$ nrz create vite my-app --allow-scripts='create-*'"
  title="Terminal"
  lang="bash"
/>
