Manage registry authentication tokens in the nrz keychain.

To target a specific configured registry by alias, use
[`nrz registry <alias> token <subcommand>`](/client/commands/registry).
See
[Targeting a specific registry](/client/registries#targeting-a-specific-registry).

## Subcommands

### list

List all tokens for configured registries. Queries each registry's
token API and displays token metadata including key, creation date,
and permissions.

<Code code="$ nrz token list" title="Terminal" lang="bash" />

### add

Add a token for the specified registry. You will be prompted to paste
the bearer token.

<Code code="$ nrz token add" title="Terminal" lang="bash" />

### rm

Remove the stored token for the specified registry.

<Code code="$ nrz token rm" title="Terminal" lang="bash" />
